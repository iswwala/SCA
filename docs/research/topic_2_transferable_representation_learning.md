# 面向跨设备侧信道分析的可迁移特征表示与网络结构研究

## 一、课题简介

侧信道分析使用设备运行密码算法时产生的物理信号作为信息来源。功耗、电磁辐射或其他测量信号通常以一维时间序列形式记录，波形中的局部变化可能与 AES 的中间值或秘密密钥有关。建模侧信道攻击的目标，是训练一个模型从轨迹中提取与密钥相关的信息，并利用多条攻击轨迹完成密钥候选排序。

深度学习模型能够直接从原始或预处理后的轨迹中学习特征，但模型学到的内容不一定全部与密钥有关。它还可能学习到设备型号、探针位置、采样时钟、噪声模式、幅值尺度和采集环境等信息。当训练设备和目标设备存在差异时，这些设备相关特征会降低模型的迁移能力。

本课题研究的核心问题是：

> 如何设计更有判别性、更稳定且更容易迁移的侧信道特征表示，使模型在设备或采集条件变化后仍能保留密钥相关信息，并提高真实密钥恢复效率？

## 二、使用的数据集

本课题建议以 ASCAD 系列作为主要开发数据，再使用 CDPA 的真实多设备数据进行外部泛化验证。这样可以把“特征结构是否有效”和“特征能否跨真实设备迁移”区分开来。

### 1. 主要开发数据：ASCAD 系列

建议使用以下数据构造不同难度的特征学习任务：

- **ASCAD fixed-key 原始版本**：用于监督建模、源域特征提取和基础 GE 评价；
- **ASCAD desync50**：用于研究中等时序错位对特征稳定性的影响；
- **ASCAD desync100**：用于研究较强时序错位下的特征鲁棒性；
- **ASCAD Gaussian Noise 或 Clock Jitter 版本**：用于研究噪声、采样扰动和特征选择的稳定性。

ASCAD 的不同版本适合用于控制单一变量，例如只改变去同步幅度而保持任务语义基本一致。它们属于**受控域偏移数据**，主要用于网络结构筛选、特征可视化、消融和机制分析，不能单独支撑“真实跨设备泛化”的结论。

### 2. 外部验证数据：CDPA 多设备与多采集条件数据

为了检验特征表示是否具有真实迁移能力，建议在后期加入 CDPA 数据中的一个或多个子集：

- **XMEGA 多芯片数据**：未防护软件 AES-128，包含 8 个芯片，可用于跨芯片特征迁移；
- **SAKURA-AES 多板卡数据**：未防护硬件 AES-128，包含 3 块板卡，可用于硬件实现下的设备变化分析；
- **CHES CTF 2018 数据**：掩码软件 AES-128，可用于测试实现和防护变化带来的更强域偏移；
- **XMEGA-EM 数据**：不同近场探针位置采集，可用于测试测量位置变化下的特征稳定性。

这些数据与 ASCAD 的任务设置、标签形式和轨迹格式可能不同，因此不应直接套用同一套预处理参数。小组应先完成数据转换和标签语义核对，再进行跨设备特征比较。

### 3. 推荐使用顺序

1. 在 ASCAD fixed-key 上确认模型能够学习有效的密钥相关表示；
2. 在 desync50、desync100 和噪声版本上筛选对时序和噪声变化稳定的表示；
3. 在 XMEGA 或 SAKURA-AES 上验证特征是否能跨真实芯片或板卡迁移；
4. 在 XMEGA-EM 或 CHES CTF 2018 上进行探针位置、测量方式或实现防护变化的扩展检验。

### 4. 数据边界

- ASCAD 原始版本与其受控变体适合做结构和机制研究；
- CDPA 多设备数据适合做真实跨设备泛化检验；
- 不同数据集的 AES 实现、泄露模型、目标字节和密钥设置可能不一致，必须分别报告；
- 如果只使用 ASCAD 及其人工去同步版本，论文表述应限定为“受控域偏移下的可迁移特征”，不应直接声称已经解决真实跨设备迁移问题。

## 二、研究背景与现状

### 1. 侧信道分析本质上是一个高维时序识别问题

一条侧信道轨迹通常包含大量连续采样点，但真正与目标密码操作相关的信息可能只集中在局部时间区间。泄露位置可能受到时钟、流水线、编译器、测量设备和噪声影响。不同轨迹中的泄露峰还可能发生平移、展宽、衰减或叠加。

在 profiling SCA 中，模型通常需要预测 256 个 AES 中间值类别之一，或者预测与密钥恢复相关的其他泄露标签。因此，模型既要发现微弱的局部时序模式，又要在多个类别之间建立稳定的判别边界。

### 2. CNN 是常用基础结构，但其特征迁移能力并不理想

一维卷积网络能够通过局部感受野和层级下采样提取波形模式，已经成为深度学习侧信道分析中的常用结构。ASCAD 等公开基准也提供了 CNN、MLP 和其他网络配置，方便研究者进行比较。

但普通串行 CNN 具有一些潜在局限：

- 固定卷积核和固定下采样路径不一定适合不同宽度的泄露模式；
- 过早下采样可能丢失微弱的局部信息；
- 过深或过宽的网络可能记住设备特征和噪声；
- 单一特征向量可能混合密钥相关因素和设备相关因素；
- 源域分类性能高，不代表目标设备上的密钥恢复性能高。

已有研究也探索了更有效的网络设计、损失函数、自动兴趣点选择、特征融合和模型可移植性。这说明“如何学习可迁移的特征”仍然是深度侧信道分析中的开放问题，而不是简单的模型替换问题。

### 3. 跨设备场景要求特征表示具有更强的稳定性

如果模型只在训练设备上测试，网络可以利用一些在该设备上稳定、但在其他设备上不稳定的线索。跨设备测试会暴露这种过拟合：源域分类器可能仍然具有较高的训练或验证准确率，但在目标设备上预测质量明显下降，导致真实密钥的排名无法下降。

因此，特征表示研究不能只关注源域 accuracy，而应同时考察：

- 同一类别在不同域中的特征是否靠近；
- 不同类别之间是否保持足够分离；
- 表示是否仍然包含设备身份信息；
- 目标域预测的置信度是否可信；
- 最终 GE、key rank 和 SR 是否改善。

## 三、拟解决的科学问题

本课题可以围绕以下问题展开：

1. 侧信道模型中的哪些特征是真正与密钥相关的，哪些特征主要反映设备或采集条件？
2. 不同时间尺度、不同感受野和不同特征路径对跨设备迁移有什么影响？
3. 提高源域分类准确率是否会同步提高目标域密钥恢复能力？
4. 怎样衡量一个特征表示的“可迁移性”？
5. 能否在不使用目标域标签的情况下，通过结构或训练目标提高表示稳定性？
6. 改进后的表示是否能够被不同的域适应方法复用，而不是只对某一个训练器有效？

## 四、研究内容

本课题不预设具体网络名称。小组应根据研究假设选择结构或训练路径，并通过对比与消融证明设计是否有必要。

### 1. 分析侧信道波形与特征表示

- 研究轨迹的长度、局部窗口、采样点和噪声特点；
- 分析去同步、幅值变化、噪声和测量条件变化造成的波形差异；
- 观察不同类别轨迹的局部模式和统计特征；
- 确定哪些特征分析方法可以辅助解释模型行为；
- 设计源域、目标域和攻击指标之间的对应关系。

### 2. 设计候选特征学习路径

可以从以下方向中选择一到两个作为主要研究方向：

- 多尺度时序建模；
- 不同感受野或不同下采样策略；
- 多分支、残差或层级特征融合；
- 重要时间区域或通道的自适应选择；
- 密钥相关信息与设备相关信息的特征分离；
- 类内紧凑与类间分离约束；
- 对比学习、一致性训练或增强不变性；
- 特征归一化、统计校准或轻量化表示；
- 其他有明确机理假设的网络或训练路径。

这里的创新不应等同于“增加更多层”。每一种结构变化都应说明它针对的是局部泄露、时序错位、噪声、类别混淆、设备差异还是计算成本问题。

### 3. 建立可迁移性评价体系

除了常规分类指标，还应评价特征表示本身：

- 类内距离和类间距离；
- 类别中心在不同域之间的偏移；
- 域判别器对特征的可识别程度；
- 预测熵、置信度和错误率之间的关系；
- 特征可视化或低维投影；
- 参数量、计算时间和显存占用；
- GE、key rank、SR 和 NTGE。

最终要判断的是：表示变化是否真正改善了跨设备攻击，而不是只改善了源域训练曲线。

### 4. 验证特征表示与域适应的兼容性

小组可以将候选特征表示接入不同的训练策略，检验：

- 表示改进是否在无域适应情况下也有效；
- 表示改进是否能增强域适应；
- 不同域适应策略是否依赖不同的 backbone；
- 某种表示是否只对特定域偏移有效；
- 结构性能提升是否来自参数量增加，而非真正的表示改进。

### 5. 完成结构消融和robust分析

建议包括：

- 原始表示与改进表示；
- 去掉核心模块后的版本；
- 不同输入窗口或偏移强度；
- 不同随机种子；
- 不同训练数据规模；
- 目标域攻击指标和特征结构指标；
- 一个计算成本或模型复杂度分析

## 五、三人小组分工建议

### 第一人：波形与特征分析

- 研究侧信道轨迹和域偏移特点；
- 进行波形、统计特征和特征空间可视化；
- 设计类内/类间分离及跨域可迁移性指标；
- 分析模型关注的时间区域和可能的泄露位置。

### 第二人：网络结构与训练路径

- 设计候选特征提取结构或表示学习目标；
- 完成网络接口、训练流程和模型保存；
- 实现核心模块和消融版本。

### 第三人：跨域验证与攻击评价

- 将不同特征表示接入跨域训练和攻击流程；
- 完成多 seed、不同域偏移和不同训练规模实验；
- 进行统计汇总、结果可视化和结论校准。

## 六、预期成果

- 侧信道特征学习与跨设备迁移的背景综述；
- 对现有特征提取路径局限性的分析；
- 一组具有明确研究假设的候选特征表示；
- 一个主要结构或训练路径改进；
- 完整的结构消融、跨域验证和效率分析；
- 特征可迁移性与密钥恢复指标之间的关系分析；
- 可复用的模型结构、特征导出、诊断和绘图工具。

## 七、课题难点与风险

- 复杂结构可能提高源域 accuracy，却不改善目标域 GE；
- 不同网络的性能差异可能来自参数量、训练预算或预处理差异；
- 特征可视化不能单独证明密钥恢复有效；
- 低维投影和类间距离指标可能受到类别不平衡或采样方式影响；
- 注意力权重不一定等于真正的密码泄露位置；
- 过多结构组件会导致消融不完整，难以解释真正的贡献。

因此，研究应坚持单变量改动、固定训练预算和攻击指标优先的原则。若最终结构没有提升 GE，也应分析“为什么分类特征没有转化为密钥恢复收益”，这本身可以成为论文中的重要讨论。
