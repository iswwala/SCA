# 面向 SCA-UDA 项目的三人本科生小组选题方案

## 1. 设计目标

本方案面向三人本科生小组，课题规模按一个完整研究模块设计，而不是单纯完成一个网络或复现一篇论文。每个方案都应同时产出：

- 一份可以独立提交的本科毕业设计报告；
- 一组可复现的代码、配置、日志、图表和数据；
- 一段可以并入当前 SCA-UDA/CDAN-SCA 主论文的研究材料。

三版方案只限定研究问题、证据要求和对项目的贡献，不固定必须使用 CDAN、DANN、注意力、原型、解耦网络或某一种损失函数。小组应先完成文献调研、数据审计和小规模预实验，再决定具体技术路线。

## 2. 与当前主论文的衔接方式

当前项目的主线是：研究无标签目标域条件下，如何改善跨设备或跨分布的 profiling side-channel analysis，并解释全局边缘对齐、类别条件对齐和目标域置信度之间的关系。

本科课题的成果可以按照以下方式并入主论文：

| 学生课题产出 | 可对应的主论文部分 |
|---|---|
| 统一数据划分、训练协议和指标定义 | Experimental Setup / Evaluation Protocol |
| 多种方法的公平对比 | Main Comparison / Baselines |
| 新结构或新训练路径 | Method Extension / Proposed Variant |
| 去掉模块、替换模块、参数敏感性实验 | Ablation Study |
| 多随机种子、不同偏移强度和不同设备 | Robustness / Generalization |
| 特征可视化、类间分离、域判别和置信度分析 | Mechanism Analysis |
| 负结果、退化场景和失败原因 | Limitations / Failure Boundary |
| 统一脚本、结果 JSON、图表和模型 | Reproducibility Assets |

这里的“并入论文”不是直接复制学生报告，而是由项目负责人根据整体论文叙事、数据来源和实验重复情况重新组织。学生课题必须保存原始结果和完整配置，不能只提交最终截图。

## 3. 三版方案总览

| 方案 | 课题定位 | 最适合转化为论文的部分 | 小组规模 | 建议周期 |
|---|---|---|---|---|
| 方案一 | 跨域方法与主实验 | 方法扩展、主对比、消融实验 | 3 人 | 12-16 周 |
| 方案二 | 表征结构与路径创新 | 网络结构、训练路径、机制解释 | 3 人 | 12-16 周 |
| 方案三 | 泛化检验与失效边界 | 鲁棒性、适用范围、负结果分析 | 3 人 | 12-16 周 |

三版可以作为三个不同小组选题，也可以在后续整合为同一篇论文的三个互补部分。若只选择一个，建议优先考虑**方案一**；它最直接地产出主论文中的实验对比和方法扩展。若当前论文已经有较完整的方法主线，则方案二或方案三更适合补强论文。

## 4. 方案一：跨域侧信道攻击方法的构建、比较与负迁移抑制研究

### 4.1 建议题目

**面向无标签目标域的跨设备建模侧信道攻击方法研究**

英文题目：**Cross-Device Profiling Side-Channel Analysis with Unlabeled Target-Domain Adaptation**。

### 4.2 课题定位

本方案承担当前项目的“方法与主实验”模块。研究重点不是复现某个固定算法，而是围绕一个明确问题构建若干有逻辑关系的技术路径：

> 在目标域没有标签时，如何减少设备或采集条件变化对密钥恢复效果的影响，并避免域适应带来的负迁移？

小组可以根据调研结果选择一种主方法，也可以组合不同层次的策略，例如特征级、类别级、统计级、伪标签级或训练策略级方法，但必须说明每条路径解决的具体问题和假设。

### 4.3 主要研究内容

- 建立统一的源域、目标域、训练集、适应集和攻击评估集划分；
- 设计不少于三类具有明确差异的技术路径，形成公平对比；
- 研究方法对目标准确率、GE、key rank、SR、NTGE 和域判别指标的影响；
- 重点检验“域混淆变好是否真的意味着密钥恢复变好”；
- 研究目标域样本量、域偏移程度、训练权重或置信度策略对结果的影响；
- 选择一条最有潜力的路径进行结构改进或训练策略创新；
- 给出主方法、基线、消融和失败案例的完整解释。

### 4.4 三人分工建议

分工不是固定实现路径，目的是覆盖完整研究链路：

1. **实验协议与数据方向**：数据审计、划分策略、预处理、可复现配置和评估脚本；
2. **模型与训练方向**：统一训练接口、候选方法实现、训练日志和模型保存；
3. **分析与验证方向**：GE/SR/NTGE、统计汇总、消融、可视化和失效分析。

三人不能只按“每人负责一个模型”切分，否则难以形成有逻辑的研究结论；每个人都应参与问题定义、实验设计和结果讨论。

### 4.5 预期成果

- 一个统一的 source-target 域适应实验框架；
- 若干具有可解释差异的对比路径，而不是简单堆叠模型名称；
- 至少一条有结构或训练机制改进的主路径；
- 多 seed 的 GE 曲线、SR、NTGE、目标准确率和域指标；
- 消融实验、参数敏感性和负迁移案例；
- 可复用的训练器、配置、评估脚本和结果汇总表。

### 4.6 可直接进入主论文的内容

该方案可以直接提供：

- **Experimental Setup**：数据、域划分、指标和公平性协议；
- **Baselines and Main Comparison**：不同域适应路径的主结果；
- **Method Extension**：小组最终选择的改进路径；
- **Ablation Study**：关键组件或训练策略的作用；
- **Negative Transfer Analysis**：域判别降低但 GE 恶化的案例及解释。

### 4.7 结题要求

不要求预先承诺“新方法一定优于现有方法”。如果改进方法没有稳定提升，也可以形成有价值的论文材料，但必须说明：

- 失败发生在哪种域偏移下；
- 是分类边界、伪标签、特征结构还是训练稳定性导致失败；
- 该结果对 CDAN-SCA 的适用条件和后续设计有什么约束。

## 5. 方案二：侧信道可迁移特征表示与网络路径创新研究

### 5.1 建议题目

**面向跨设备侧信道分析的可迁移特征表示与网络结构研究**

英文题目：**Transferable Representation Learning and Network Design for Cross-Device Side-Channel Analysis**。

### 5.2 课题定位

本方案承担当前项目的“模型结构与路径创新”模块。研究不以某一种预设网络为答案，而是考察：

> 什么样的波形特征表示，能够同时保留密钥相关信息、增强类别可分性，并减少设备或采集条件变化造成的影响？

小组可以从时序建模、特征尺度、分支结构、信息筛选、表示约束、可逆或非可逆变换、轻量化等方向选择研究路径。重点是建立结构设计与侧信道机理之间的联系，而不是单纯增加层数。

### 5.3 主要研究内容

- 梳理当前 `feature_extractor.py`、`classifier.py` 和监督训练流程的能力与局限；
- 分析泄露峰位置、宽度、局部波形、去同步和噪声对特征学习的影响；
- 设计一组具有不同归纳偏置的候选特征提取路径；
- 研究特征表示对源域分类、目标域迁移和最终密钥恢复的影响是否一致；
- 分析特征的类内紧凑性、类间分离、域可分性和置信度；
- 选择最有意义的结构或训练路径，与当前项目的域适应模块进行组合验证；
- 在参数量、训练成本和攻击性能之间进行权衡分析。

### 5.4 三人分工建议

1. **波形与表示分析方向**：数据可视化、时序偏移分析、特征诊断和可解释性；
2. **模型结构方向**：候选 backbone、结构接口、参数量和训练稳定性；
3. **跨域验证方向**：将候选表示接入现有训练与 GE 评估链路，完成跨域、消融和鲁棒性对比。

### 5.5 预期成果

- 可配置、可替换的特征提取框架，能够接入当前监督训练和 UDA 训练；
- 不同表示路径的公平比较；
- 一个有明确动机的结构改进或训练路径；
- 特征空间诊断工具，包括类间/类内距离、域差异、可视化或置信度分析；
- 关于“分类指标、表征指标和密钥恢复指标是否一致”的实验结论。

### 5.6 可直接进入主论文的内容

该方案可以直接提供：

- **Backbone or Representation Design**：改进后的特征表示结构；
- **Architecture Ablation**：不同尺度、分支、约束或特征路径的消融；
- **Mechanism Analysis**：结构如何改变类间分离和域差异；
- **Efficiency Analysis**：参数量、训练时间、显存和攻击效率；
- **Compatibility Experiment**：改进 backbone 与 CDAN-SCA 或其他域适应方法的组合结果。

### 5.7 结题要求

不能以“源域准确率提升”作为唯一结论。至少需要回答以下问题中的两个：

- 改进表示是否改善目标域 GE 或 NTGE？
- 改进表示是否降低了类间碰撞或增强了类内紧凑性？
- 改进表示是否改变了域判别难度？
- 改进表示能否被不同域适应训练策略复用？
- 性能提升是否值得额外计算成本？

## 6. 方案三：跨设备侧信道攻击的泛化检验、鲁棒性与失效边界研究

### 6.1 建议题目

**跨设备侧信道分析方法的泛化能力、鲁棒性与失效边界研究**

英文题目：**Generalization, Robustness, and Failure Boundaries of Cross-Device Side-Channel Analysis**。

### 6.2 课题定位

本方案承担当前项目的“检验与边界”模块。研究不预设哪一种域适应方法获胜，而是建立一套足以检验主论文结论的实验体系：

> 一个方法在什么样的域偏移下有效？它的改进来自哪里？在什么条件下会退化甚至产生负迁移？

该方案尤其适合当前项目，因为现有记录已经指出：真实 CDAN/CDAN-SCA 结果、更多域偏移、统一多 seed 和完整鲁棒性证据仍然不足。

### 6.3 主要研究内容

- 建立受控域偏移与真实跨设备设置的分层实验；
- 比较单源单目标、多源单目标、留一设备和不同目标域样本量等设置；
- 研究去同步、噪声、幅值变化、采样变化、探针位置或实现差异等因素；
- 设计多 seed、重采样、不同训练预算和不同偏移强度的稳定性检验；
- 比较 accuracy、GE、SR、NTGE、域准确率和特征结构指标之间的关系；
- 建立方法性能随偏移强度变化的曲线或边界图；
- 选择一个最关键的失效机制，提出针对性的路径改进或诊断指标；
- 区分“算法无效”“数据契约错误”“训练不稳定”和“评价指标不匹配”。

### 6.4 三人分工建议

1. **数据与域偏移方向**：数据集整理、偏移生成或设备配对、实验矩阵和数据契约；
2. **方法与复现实验方向**：统一运行多种候选方法，管理 seed、训练预算和模型产物；
3. **统计与边界分析方向**：置信区间、敏感性、失败案例、可视化和结论校准。

### 6.5 预期成果

- 一个跨设备/跨分布侧信道实验基准和配置体系；
- 多种方法在多种偏移条件下的结果矩阵；
- 稳定性、敏感性和错误分析报告；
- 方法有效区间、退化区间和失败边界；
- 一个针对关键失效机制的改进尝试或诊断方法；
- 能够被主论文直接引用的鲁棒性表格、边界图和补充实验。

### 6.6 可直接进入主论文的内容

该方案可以直接提供：

- **Robustness and Generalization**：多设备、多偏移、多 seed 结果；
- **Sensitivity Analysis**：目标样本量、偏移强度、训练权重和模型设置；
- **Failure Boundary**：CDAN-SCA 或其他方法的适用条件；
- **Evaluation Validity**：说明 accuracy、domain accuracy 和 GE 之间的差异；
- **Appendix or Supplementary Experiments**：更全面的数据和协议审计。

### 6.7 结题要求

不能只罗列大量实验表格，必须形成一个边界结论，例如：

- 某类语义保持的波形偏移更适合无监督适应；
- 某种严重偏移会导致高置信错误，熵筛选不再可靠；
- 域判别准确率下降不代表密钥恢复能力提高；
- 结构改进只在中等偏移下有效，强偏移下需要额外信息；
- 某种复杂方法在有限目标样本下不如简单策略稳定。

## 7. 三人小组的共性工作量要求

无论选择哪一版，建议将以下内容作为共同底线：

1. 完成当前训练、测试、模型保存和 GE 评估入口的路径与接口整理；
2. 形成统一的配置文件，记录数据、seed、模型、训练预算和指标；
3. 至少覆盖 Source Only 和一种域适应或跨域改进路径；
4. 至少运行 3 个随机种子，保存逐 seed 原始结果；
5. 至少完成一个核心变量的消融或敏感性实验；
6. 同时报告分类指标和攻击指标，不能只报告 accuracy；
7. 输出代码、配置、日志、模型、预测概率、GE 曲线和汇总表；
8. 对失败结果和数据限制进行说明，不把 synthetic smoke 当成科学证据；
9. 将最终结果整理为论文可直接使用的图表和文字说明初稿。

## 8. 选题与主论文模块的对应关系

| 论文需要 | 更适合的题目 |
|---|---|
| 缺少统一的主实验和方法对比 | 方案一 |
| 缺少网络结构或训练路径创新 | 方案二 |
| 缺少多场景检验、鲁棒性和失败分析 | 方案三 |
| 三人小组希望共同推进 CDAN-SCA 主线 | 方案一 |
| 已有主方法，想补充模型机制 | 方案二 |
| 已有初步结果，想提高论文可信度 | 方案三 |

## 9. 最终建议

如果该三人小组的成果需要最大程度服务当前项目论文，建议优先采用以下题目：

> **面向无标签目标域的跨设备建模侧信道攻击方法研究**

理由是它可以同时容纳多种实验对比、主方法路径探索、消融检验和负迁移分析，最后自然形成主论文的实验主体。题目不限制小组最终选择 CDAN、原型约束、特征统计对齐、表示学习或其他路线，能够根据真实实验结果调整研究方向。

如果当前项目已经确定主方法，不希望本科小组重新承担方法主线，则选择方案二或方案三：前者为论文补充结构创新，后者为论文补充检验、鲁棒性和适用边界。
