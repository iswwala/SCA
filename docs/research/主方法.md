# 当前项目主方法说明

## 1. 方法定位

当前项目的基础主线方法是 **CDAN-SCA**：面向跨设备建模侧信道攻击的条件域对抗无监督域适应方法。

研究设置为：

```text
源域：有标签 profiling 轨迹
目标域：无标签目标设备或偏移条件轨迹
目标：改善目标域密钥恢复，而不仅是提高分类准确率
```

核心问题是：相比 Source Only、DANN 和 CDPA/MMD，类别条件域对齐能否减少跨设备侧信道攻击中的负迁移，并改善 GE、key rank 和攻击轨迹成本。该问题目前仍需通过统一实验验证。

## 2. CDAN-SCA 基础方法

方法包含：

1. 一维波形特征提取器；
2. 256 类泄露类别分类器；
3. 特征与分类预测的条件表示；
4. GRL 域对抗训练；
5. 目标域预测熵或置信度加权。

训练流程：

```text
x_s, y_s -> feature extractor -> f_s -> classifier -> g_s
x_t     -> feature extractor -> f_t -> classifier -> g_t

(f_s, g_s), (f_t, g_t)
        -> conditional representation T(f, g)
        -> GRL -> domain discriminator
```

基本目标函数：

```text
L = L_cls(source) + lambda_adv * L_domain(T(f, g))
```

普通 DANN 只输入 `f`，CDAN-SCA 使用 `T(f, g)`。`T(f, g)` 可以是直接外积、随机多线性映射或其他经实验验证的低维条件表示。

由于直接外积维度可能过大，当前优先采用随机投影或随机多线性映射，但投影维度必须做敏感性或消融实验。

## 3. 目标域置信度加权

目标域没有标签，分类器预测可能包含错误伪标签。因此当前论文实验拟统一采用归一化熵权重：

```text
H(g) = - sum_k g_k log(g_k)
w(g) = 1 - H(g) / log(256)
```

低熵样本权重较大，高熵样本权重较小。但低熵不一定代表预测正确，模型可能出现 `confident wrong`，所以熵加权有效性必须通过实验检验。

旧版 `experiments/legacy/CDAN/dann.py` 使用的是另一种指数权重并进行 batch 归一化。正式实验前必须统一公式，不能将两种实现混为一个方法。

## 4. 当前优先创新方向

CDAN-SCA 是基础主线。为了避免论文被评价为“直接将 CDAN 应用于 SCA”，当前优先考虑的 SCA-specific 扩展是：

> **校准感知 CDAN-SCA：使用更可靠的目标域置信度估计替代未经校准的熵权重。**

拟解决的问题：

```text
目标域无标签
    -> 分类器置信度可能失真
    -> 熵权重可能强化 confident wrong
    -> 错误条件对齐导致负迁移
```

可选实现包括源域验证集温度校准、校准置信度权重、置信度阈值和动态权重。该方向目前是优先候选创新，不是已经完成并验证的最终方法。只有当基线实验确认普通熵权重存在可靠性问题后，才将其确定为正式 Proposed Method。

## 5. 暂不并行加入的方向

以下方向暂作为备选，不与校准方向同时加入：

- **类别原型保持**：维护源域类别原型，减少类别混淆和伪标签漂移；
- **稀疏或类别平衡条件化**：研究目标域伪标签集中于少数类别时的适应问题；
- **时域偏移建模**：研究去同步、轻量注意力或多尺度特征。

这些都是待验证方向，不能在实验前写成既定创新。ASCAD `desync50/desync100` 是受控去同步实验，不等同于真实跨设备验证。

## 6. 基线、主方法和消融

### 外部基线

```text
Source Only
DANN
CDAN（无熵权重）
CDPA/MMD
AdaBN 或其他简单统计适应方法（若实现）
```

### 当前主方法

```text
CDAN-SCA full
```

至少包含条件域表示、GRL 域对抗和统一规定的目标域置信度/熵权重。

### 主方法消融

```text
CDAN-SCA without conditional input
CDAN-SCA without entropy/confidence weighting
不同条件投影维度
不同域适应权重
校准感知 CDAN-SCA（若正式确定）
```

去掉条件输入的变体用于分析 DANN 式边缘对齐，属于主方法内部消融，不替代独立 DANN 基线。

## 7. 推荐实验路线

```text
E0：ASCAD fixed-key -> ASCAD fixed-key 的 Source Only 流程验证
E1：MLP、官方 CNN、ResNet1D/MultiResNet 结构复现
E2：ASCAD fixed-key -> desync50/desync100 的方法基线
    Source Only、DANN、CDAN、CDPA/MMD
E3：CDAN-SCA 主方法
E4：条件输入、熵权重、投影维度和适应系数消融
E5：校准感知 CDAN-SCA 候选创新
E6：CDPA-XMEGA 真实跨设备验证
```

## 8. 数据划分和评价指标

受控偏移实验：

```text
Source: ASCAD fixed-key
Target: ASCAD desync50 / desync100
```

真实跨设备实验：

```text
Source: CDPA-XMEGA 中的源设备
Target: CDPA-XMEGA 中的其他设备
```

每个实验必须分开记录：

```text
source_train
source_val
target_adapt
target_attack
```

目标域适应轨迹不能与最终攻击轨迹混用，并说明是否计入总攻击成本。

主要指标：

- GE 曲线；
- key rank；
- 固定轨迹数下的成功率；
- 达到 `GE=1` 或 `rank=0` 所需攻击轨迹数；
- 总轨迹成本。

辅助指标：target accuracy、domain accuracy、预测熵、ECE/Brier、类内/类间距离及训练损失。不能只凭 domain accuracy 下降或 accuracy 上升宣称方法有效。

## 10. 最终统一表述

> 本项目研究跨设备建模侧信道攻击中的无监督域适应问题，基础方法为 CDAN-SCA。该方法利用分类预测条件化域对抗表示，并对目标域样本进行置信度加权，以减少全局边缘对齐可能造成的类别结构破坏。项目首先通过 Source Only、DANN、CDAN 和 CDPA/MMD 建立公平基线，再验证 CDAN-SCA 在受控去同步和真实跨设备条件下对 GE、key rank 和攻击轨迹成本的影响。若实验确认未经校准的熵权重存在 confident wrong 问题，则进一步研究校准感知 CDAN-SCA 作为 SCA-specific 方法扩展。

这段表述不预设实验结果，也不把候选方向、实验假设和已验证结论混在一起。
