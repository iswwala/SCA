## 2. 新机器搭建环境

可以使用以下命令创建环境：

```bash
python3 -m venv ~/venvs/tf
source ~/venvs/tf/bin/activate
python -m pip install --upgrade pip
```

安装当前项目的核心依赖：

```bash
python -m pip install \
  tensorflow==2.21.0 \
  h5py==3.14.0 \
  numpy==2.5.2 \
  scikit-learn==1.9.0 \
  matplotlib==3.11.1 \
  tqdm==4.70.0 \
  pandas==3.0.5 \
  scipy==1.18.0
```

## 3. TensorFlow 设备检查

检查 TensorFlow 是否能使用 GPU：

```bash
~/venvs/tf/bin/python - <<'PY'
import tensorflow as tf

print("TensorFlow:", tf.__version__)
print("CPU:", tf.config.list_physical_devices("CPU"))
print("GPU:", tf.config.list_physical_devices("GPU"))
PY
```

当前环境可以识别 TensorFlow，但实际验证结果为 CPU 设备；虽然主机可以通过 `nvidia-smi` 识别 NVIDIA 显卡，TensorFlow 仍提示缺少可加载的 GPU 运行库。因此当前环境可以运行功能检查和小规模实验，但正式训练前应确认 CUDA/cuDNN 与 TensorFlow 版本匹配。

GPU 检查命令：

```bash
nvidia-smi
```

如果 TensorFlow 输出为空：

```text
GPU: []
```
